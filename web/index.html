sk-engines

SD card tools for the spotykach engines. Everything runs in this tab: nothing is uploaded, and no account, install or server is involved.

The card rules are generated from scripts/card_layout.py, so this page and the command-line tools cannot disagree about them.

Project page

Overview

The Flash tab writes the application region only, so an interrupted write costs a re-flash rather than a device. Installing a bootloader is not done here: that is the write that can genuinely brick a unit, and the Daisy Web Programmer and dfu-util both do it.

The rules on this page are generated from scripts/card_layout.py, so they match the firmware rather than paraphrasing it. Same checks as python3 scripts/sk_card.py verify.

sk-card

Build, fill and check an SD card for the spotykach engines. Everything runs in this tab — no upload, no install, no account. New card? Start on Build.

Flashing firmware is not done here. Use the Daisy Web Programmer, which already flashes this hardware — a half-written image is the worst failure in the system and is not worth a second implementation.

The rules on this page are generated from scripts/card_layout.py, so they match the firmware rather than paraphrasing it. Same checks as python3 scripts/sk_card.py verify.
